# DAA Activity - 2

This repository contains five Python programs implemented as part of the
Design and Analysis of Algorithms (DAA) Activity-2.

## Programs

### 1. Longest Palindromic Substring
Finds the longest substring that reads the same forward and backward.

### 2. Implement Trie
Implements a Trie data structure with operations such as insertion,
searching, and prefix checking.

### 3. Subarray Sum Equals K
Finds the number of continuous subarrays whose sum is equal to K.

### 4. Search in Rotated Sorted Array
Searches for a target element in a rotated sorted array using binary search.

### 5. Minimum Window Substring
Finds the smallest substring that contains all the characters of a given
target string.

## Files

- longest_palindromic_substring.py
- implement_trie.py
- subarray_sum_equals_k.py
- search_rotated_sorted_array.py
- minimum_window_substring.py

## Programming Language

Python

## Purpose

This activity demonstrates the implementation of important algorithms and
data structures used in Design and Analysis of Algorithms.
